
# 🛡️ PHISHGUARD

### Intelligent Phishing Detection & URL Risk Analysis

PHISHGUARD is an open-source cybersecurity project designed to help users identify suspicious URLs and potential phishing attempts through lightweight security analysis.

## 🚀 Features

- URL risk scoring
- Suspicious URL pattern analysis
- PayPal impersonation indicators
- Detection of suspicious keywords
- Security findings with explanations
- Simple and interactive web interface

## 🛠️ Technologies

- Python
- Streamlit
- URL Parsing
- Cybersecurity Heuristics

## 📂 Project Structure

```text
PHISHGUARD/
├── app.py
├── detector.py
├── requirements.txt
└── README.md
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/PHISHGUARD.git
cd PHISHGUARD
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## ⚠️ Disclaimer

PHISHGUARD is an educational cybersecurity project.
Its heuristic analysis is not guaranteed to identify all phishing URLs.
A low risk score does not guarantee that a website is safe.
